# Информационная система и API на JavaSpring
В данном репозитории представлено веб-приложение с информационной системой и API разработанные в ходе изучения возможностей фреймворка Spring для языка Java. 

**Архив имеет следующее содержимое:**
- AccessProject - Проект, содержащий веб-приложение (JavaSpring) для развёртывания сайта с системой управления базой данных магазина с реализацией полного CRUD, поиска, управления связями между сущностями, возможностью регистрации и авторизации пользователей, разграничением доступа и распределением функционала по ролям. Обращение к базе данных обеспечивается через запросы к отдельному API приложению (ApiProject).
- ApiProject - Проект, содержащий веб-приложение (JavaSpring) для развёртывания API с необходимостью аутентификации, разграничением доступа и функционала по ролям и с возможностью управления локальной БД магазина.
